## Play Here ----> https://artifactdle.vercel.app

Artifactdle is a Wordle-style game for guessing artifact sets from Genshin Impact. You pick an artifact set from the list of sets, and get guess feedback based on the set's region, 2pc and 4pc buffs and release version, with the aim of guessing the randomly selected artifact set within five guesses. The game features a daily mode, as well as infinite. Additionally, different game modes such as normal , silhouette and build are available. Built with React, Tailwind and Framer Motion, and inspired by the already exisitng [Genshindle](https://genshindle.com), but for artifact sets.

## How To Play (normal mode)

1. A random, unknown artifact set is selected.
2. Type and select an artifact set from the given list.
3. The game compares your guess and tells you which attributes (name, region, 2pc buff, 4pc buff & release version) are a match or close match to the answer.
4. Keep guessing until either you guess the correct artifact set or hit 5 guesses.
5. Try to build up a streak of wins and aim for a high score.

## Download and Run

### Prerequisites

- **Node.js** 18+ and npm
  
### Run Locally
```bash
git clone https://github.com/ThomasFraserDev/artifactdle.git
cd artifactdle
npm install
npm run dev
```
